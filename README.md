# 洛克王国通行证拼团结算工具

一个用于计算《洛克王国》通行证「传火」拼团方案的网页工具。自动生成最优传火结构、计算每人应付金额与转账指令，并支持导出矢量图 / 复制文字版分享到群里。

> 在线体验：<https://rocom-pass-the-torch.pages.dev/>

## 房间：多人一起填

把链接发到群里，每个人点开填自己的信息，所有人看到同一份数据：

1. 点「创建房间」，复制生成的链接发到群里
2. 成员点开链接自动进入同一房间（链接里的 `?r=<房间码>` 生效）
3. 各自填完点「确认」，数据自动汇总；约 15 秒同步一次
4. 任何人都可点「生成传火方案」看结果

- 不建房间也能用，此时就是纯本地（与以前一样），不强制联网
- 头像会随房间同步，群里能看到彼此头像
- 删除成员需二次确认；删除后别人的旧数据不会把它「复活」
- 房间码是 16 位随机串，知道码才能读写；也可手动删除房间
- **房间 72 小时后自动销毁**，房间条上有倒计时。KV 的 TTL 每次写入都会重置，
  所以只要有人点「确认」就会重新计时——不用担心聊着聊着房间没了
- 头像等数据存在 Cloudflare KV（美国节点），介意的话可以不建房间、纯本地使用

## 功能特性

- 🌳 **传火结构树**：豪华版能送 2 张副券，所以结构不是一条链而是**树**。按真实父子关系布点，每条边就是一次副券赠送；细长的链横着画，有分叉时竖着画成树形。
- 📏 **节点宽度自适应**：用 canvas `measureText` 量名字宽度，长名字不会被截断或撑破。
- 🎨 **非好友段橙色虚线**：副券只能送给好友，需要临时加好友的段会标出来。
- 💰 **费用自动结算**：按**等额优惠**分摊——每人净支出 = 自己档次原价 − 人均节省额。全员同档次时等价于平摊；档次不同时不能按总额平摊，否则买普通版的人会替买豪华版的人垫钱。
- 🚗 **车头自购价**：车头若从非官方渠道购买通行证，可填实际花费（只在选中车头后出现）。**渠道盈亏归车头本人**，不影响其他人；高于官方价时按官方价计——比官方贵的话本来就该直接在官方买。
- 📝 **树节点自带全部账目**：每个人的头像、角色、档次·精灵、实付、结算转账、净支出、省了多少，全部直接标注在节点上，不用再翻下面的列表。
- 🖼️ **导出矢量图**：按数据程序化生成 SVG（宽度固定 750，树放不下自动蛇形换行），再转 PNG。矢量渲染放大不糊，12 人的图约 800px 高。
- 📋 **复制文字版**：一键复制可直接粘贴到群里的结算文本。微信里图片要「保存 → 相册 → 发群」绕一大圈，文字版反而更快，还能编辑、能 @ 人。
- 📱 **微信长按保存**：微信内置浏览器不认 `a[download]`，所以微信内导出后直接展示图片，提示长按保存 / 转发。
- 🎛️ **精灵设置**：精灵名称与介绍图在「精灵设置」里改，草稿编辑 + 点「确认」才生效。直接绑定真值的话，输入到一半的名字会被 15 秒一次的轮询广播给全群。
- 🪪 **可选头像与 ID**：每位成员可粘贴（Ctrl+V）/ 上传图片设置头像，自动等比压缩至 128 × 128；可填入自定义 ID / 备注。
- 📱 **响应式适配**：手机端紧凑单列、PC 端宽屏双列布局，自动跟随系统深色模式。
- 👤 **预置成员**：把 `名称-UID.jpg` 放进 `users/` 目录，页面加载时自动录入（详见该目录的 README）。

## 玩法背景

洛克王国通行证支持「副券」机制：购买通行证后可向好友赠送副券激活其通行证，副券价格远低于通行证原价。多人组成「传火结构」交替购买可让每人均摊到更低的价格。

价格表（默认）：

| 档次 | 通行证 | 副券 | 可送出 |
| --- | --- | --- | --- |
| 普通 | 68 元 | 40 元 | 1 张普通副券 |
| 豪华 | 128 元 | 80 元 | 1 张豪华 + 1 张普通副券 |

规则：

- 副券必须是**另一种精灵**；想要豪华的人只能收豪华副券，普通同理
- 副券费由**接收者**按自己的档次付
- 需互为好友才能赠送

> 因为豪华版能送 2 张，一个人可以同时激活两个人，所以结构是**树**而不是链。
> 这也是算法从线性 DFS 改成树搜索的原因。

> 算法上，**好友关系是软约束**：它不参与可行性判定，只作为优化目标（尽量让好友相邻）
> 与事后提示。硬性要求「相邻必为好友」极易导致无解，而现实中非好友相邻也能靠临时
> 加好友解决。

### 开发容器通过代理域名访问

容器里跑 dev server 时，Vite 默认只放行 `localhost`，用平台分配的域名访问会
返回 `Blocked request`。`vite.config.js` 里已放行 `.cnb.run` / `.cnb.cool`：

```js
server: { allowedHosts: ['.cnb.run', '.cnb.cool'] }
```

> 必须以 `.` 开头才表示「含子域」——Vite 的匹配是 `hostname.endsWith(allowedHost)`，
> 写 `cnb.run` 只精确匹配自身，匹配不到 `xxx-5173.cnb.run`。

## 核心算法

`src/utils/calculator.js` 的 `generatePlan()` 是核心入口：

1. **校验输入**：人数 ≥ 2；车头最多一人且必须是豪华版（普通版送不出豪华副券，树会长不开）。
2. **构建好友邻接表**：基于双向好友对。
3. **枚举树的形状**：根集合取 1~3 个，每个根枚举精灵分配，逐层把待分配的人匹配到上一层提供的副券槽位上。只有两种精灵，所以每层精灵由「根精灵 + 层数奇偶」唯一确定，搜索空间大幅收缩。
4. **结算费用**：根自购通行证、其余人付副券费，再按**等额优惠**分摊。

### 分摊规则（真金白银，重点）

```
每人净支出 = 自己档次原价 − 人均节省额
```

不能简单 `总额 / 人数` 平摊：档次不同意味着拿到的东西不同，平摊会让买豪华的人
拿走几乎全部优惠、买普通的人几乎不省甚至倒贴。例：1 豪华 + 1 普通，总价 168，
平摊 84，而普通版原价才 68——等于让他倒贴 16 元。

两条边界保护：

- **净支出不为负**：车头自购价极低时（低于人均节省额），份额会算成负数，
  等于参加拼团还倒收钱。截断到 0，差额从净支出为正的人身上按额度扣回，总额仍闭合。
- **车头渠道盈亏归车头本人**：他找到便宜渠道不该让全团跟着沾光，买贵了也不该
  让别人替他背锅。填 9999 这种异常值不会摊到全团头上。

### 导出图

`src/utils/planSvg.js` 按数据重新画一张 SVG，而不是截 DOM：

- 宽度固定 750，树放不下自动换行
- **蛇形排列**（奇数行反向）：否则上一行末尾要连到下一行开头，连线得横跨画布、
  从别的节点底下穿过去
- 只有纯链（每个节点最多一个子节点）才横着排；有分叉就竖着画成真正的树形
- 箭头是手画的三角形，不用 SVG `<marker>`——`markerUnits` 默认会乘以线宽，
  各渲染器处理不一致，箭头容易比连线还长糊到卡片上

## 调试：导出图验证页

部署后访问 `/verify`（或本地 `/verify.html`）：

- **三种渲染并排**：内联 SVG / `<img>` 加载 / canvas → PNG（实际导出流程）。
  一眼看出问题在 SVG 本身，还是在 SVG → canvas 这一步
- **诊断面板**：打印 SVG 声明尺寸与浏览器解析出的实际尺寸；不一致就说明
  `drawImage` 会非等比拉伸
- **5 个预设用例**：4 人链 / 8 人分叉 / 12 人长链 / 带头像 / 车头自购价

> 排查导出图问题时**不要**用第三方 SVG 渲染器（如 resvg）的截图下结论——
> 它和浏览器的解析行为不一致，会掩盖真实问题。

## 配置文件格式

```json
{
  "version": 1,
  "exportedAt": "2026-05-21T12:00:00.000Z",
  "elfName1": "新月鹭",
  "elfName2": "热团团",
  "elfImg1": "https://…/elf1.webp",
  "elfImg2": "https://…/elf2.webp",
  "maxGaps": 0,
  "people": [
    { "id": "9489b62a", "name": "菠菜", "userId": "2089631", "avatar": "",
      "tier": "normal", "needElf": "elf2", "isHead": false, "headPrice": null }
  ],
  "friendships": [["35e4ff86", "78eb4639"]]
}
```

| 字段 | 说明 |
| --- | --- |
| `tier` | 档次，`normal` / `premium`（每人独立） |
| `needElf` | 精灵需求，`elf1` / `elf2` / `any` |
| `isHead` | 车头，最多一人，必须 `premium` |
| `headPrice` | 车头自购通行证的实际花费；`null` 或留空按官方价计。仅对车头生效，且不能高于官方价 |
| `elfName1/2`、`elfImg1/2` | 精灵名称与介绍图链接（介绍图只接受 http(s) 外链） |
| `maxGaps` | 最多留几个空位，`0` = 只给确定方案；`1` / `2` 会额外计算「再拉 N 人能省多少」 |
| `userId` | 可选，自定义 ID 或备注 |
| `avatar` | 可选，`data:image/...` 图片 data URL；导入时只接受合法图片 data URL |
| `friendships` | 双向好友对 `[idA, idB]` |

导入时会做结构校验与 id 合法性检查，非法字段被忽略而非中断流程。
